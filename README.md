Ember Warden — an arena-survival game: hold the last lantern against the shadow tide. Move with WASD or arrows, your lantern fires on its own, dash with Space, gather embers, level up and choose blessings, and slay the Night Herald in wave 5 to bring the dawn. Five waves, four shadow kinds plus a boss, twelve upgrades, synthesized sound, particles and floating damage numbers — all in plain HTML, CSS and JavaScript with no build step and no network requests.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
